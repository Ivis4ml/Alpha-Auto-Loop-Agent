## 一、我方访问方式描述

现有参考爬虫（crawler_cls）直连 `https://www.cls.cn/v1/roll/get_roll_list` JSON 接口，
带站点自身前端使用的签名算法，进程内令牌桶限速默认 2 QPS，单进程运行，只读取公开
电报内容。本机已积累 2020-01-01 至 2026-06-18 约 89 万条历史语料。本项目原计划恢复
实时采集并补抓缺口，采集产出仅用于本机个人研究，不对外发布原始抓取数据。

## 二、核实所见

### robots.txt

仅禁止若干站点验证文件与图片后缀（jpg/jpeg/gif/png/bmp），未禁止 `/v1/` 接口路径或
电报页面路径。需要说明：robots.txt 是对搜索引擎爬虫的抓取指引，不构成对程序化访问
的授权，也不能覆盖服务协议中的相反约定。

### 《用户使用协议》关键条款（摘录自存档快照）

- 第 2.3.1 条：许可为"个人的、不可转让及非排他性的"，且限定"为非商业目的在单一台
  终端设备上安装、使用、显示、运行本软件"。
- 第 2.3.3 条：未明示授权的一切权利保留，行使须另行取得书面许可。
- 第 8.2.3 条：未经书面许可，不得对其拥有知识产权的内容"进行使用、出租、出借、复制、
  修改、链接、转载、汇编、发表、出版、建立镜像站点等"。
- 第 8.2.4 条：不得对"软件运行过程中客户端与服务器端的交互数据"进行复制、修改、
  增加、删除、挂接运行或创作衍生作品，"形式包括但不限于使用插件、外挂或非上海界面
  财联社科技股份有限公司经授权的第三方工具/服务接入本软件和相关系统"。
- 第 9.2 条：未经书面同意，"不得为任何商业或非商业目的自行或许可任何第三方实施、
  利用、转让上述知识产权"。

另据公开资料，财联社对单篇文章转载实行付费书面授权制（按千字计费，限定转载平台）。

## 三、结论

**核实结论为存在实质合规风险，不能认定"已获授权"。** 具体判断：

1. 直连 `get_roll_list` 接口属于协议第 8.2.4 条所述"非授权第三方工具/服务接入本软件
   和相关系统"的字面范围；对返回数据的持久化存储属于对"客户端与服务器端交互数据"
   的复制。
2. 协议第 9.2 条对内容利用的限制同时覆盖商业与非商业目的，"个人研究用途"并不落入
   明示的豁免。
3. robots.txt 未禁止相关路径这一事实不能推翻上述协议条款。

对本项目的边界建议（最终取舍由用户决定，本记录只陈述事实与风险）：

- **恢复主动采集**：属于持续性的新增接入行为，协议风险如上，未经用户明确知情确认
  不应启动。
- **使用已有存量语料做本机离线研究**：数据已在本机磁盘，属既成事实；继续仅限本机、
  不对外发布原始数据、不再新增抓取，是风险最低的姿态。参考仓库 minute_factor_agent
  的既有立场（"对外仅交付代码与字段 schema，不发布原始抓取数据"）与此一致。
- **替代路径**：新闻源在本项目中为可插拔设计。若放弃财联社主动采集，A 股侧可退化为
  存量语料离线研究，或另行评估有公开 API 与明确许可条款的新闻源；美股侧不受影响
  （Alpha Vantage NEWS_SENTIMENT 为授权 API）。
